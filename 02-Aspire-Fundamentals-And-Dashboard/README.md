# 02. .NET Aspire Fundamentals, AppHost & Dashboard

> Оркестрація розподілених додатків за допомогою .NET Aspire: проєкт AppHost як інфраструктурний маніфест C#, автоматичний запуск контейнерів Redis та RabbitMQ, Service Defaults для уніфікованої телеметрії та перевірки працездатності, Service Discovery та інтерактивний Aspire Dashboard.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Оркестрація:** .NET Aspire 9.5+ / 10
- **Брокер повідомлень:** RabbitMQ + MassTransit (Custom & Outbox)
- **Кеш & Сховище:** Redis, SQL Server, PostgreSQL

---

## 📂 Вміст модуля
У цьому модулі представлені готові виробничі зразки мікросервісних компонентів та архітектурних рішень.

## 🚀 Запуск
```bash
cd 02-Aspire-Fundamentals-And-Dashboard
dotnet build
```
